Why Is My Mac So Slow? 8 Causes and How to Fix Each One

A slow Mac usually has one of 8 causes: a full disk, memory pressure, a runaway process, login items, heat or old hardware. Find yours in 5 minutes and fix it.

K
Kapil • Updated Sep 27, 2026 • 8 min read

A Mac is slow for one of a handful of reasons: the startup disk is nearly full, memory is under pressure, one process is hogging the CPU, too much starts at login, macOS or an app is out of date, or the Mac is running hot. You can tell which in about five minutes with Activity Monitor and the Storage screen, and most of the fixes cost nothing.

This guide starts with that five-minute check, because fixing the wrong thing is how people spend an afternoon clearing caches on a Mac whose real problem is a 98% full disk. Then it covers the eight causes, the fix for each, and the order to try them.

Find the cause first: a 5-minute check

Do these four things before changing anything.

  1. Check free space. Open System Settings > General > Storage. If the bar shows less than about 10% free, the disk is your problem. macOS uses free space for swap and temporary files, and it slows down noticeably when it runs out.
  2. Check memory pressure. Open Activity Monitor, click the Memory tab, and look at the Memory Pressure graph at the bottom. Green is fine. Yellow means macOS is compressing memory. Red means it's swapping to disk, and that's when everything crawls.
  3. Check the CPU. Click the CPU tab and sort by % CPU. One process sitting at the top using 100% or more of the CPU is a runaway.
  4. Count what starts at login. Open System Settings > General > Login Items & Extensions. Each item in Open at Login is something running before you've opened a single window.

Why is my Mac so slow? The 8 causes

1. The startup disk is nearly full

macOS needs free space to work. When the disk is close to full it can't swap memory to disk, can't write caches, and Spotlight and Photos stall. Everything feels slow, and it gets worse the fuller the disk is.

Fix: Get back to at least 10 to 15% free. The biggest wins are usually local Time Machine snapshots, old device backups, app caches and leftovers from deleted apps.

2. Memory is under pressure

Every open app, browser tab and background helper takes memory. When the total passes what your Mac has, macOS compresses what it can and then swaps the rest to disk, which is far slower than RAM.

Fix: Quit apps you're not using, close tabs, and restart the browser once a day if you keep dozens open. Avoid memory cleaner apps; they usually make things slower by fighting the macOS kernel.

3. One process is hogging the CPU

A single misbehaving process can pin the CPU and slow everything else. Common ones are rogue browser tabs, indexing services like mds_stores, or kernel_task (which usually means your Mac is overheating).

Fix: Quit the app behind the process using Activity Monitor. If it's indexing, just wait.

4. Too much starts at login

Every login item takes memory and CPU from the moment you log in. Apps add themselves without asking, and the list only grows.

Fix: Turn off anything you don't need running all the time in System Settings.
